# Stage A: connected teaching sequence

Status: replacing two rejected prototypes. Product acceptance has **not** occurred. This is a representative opening sequence for review, not a full curriculum or a proficiency claim. It spans the opening greeting/naming work and a small person-form contrast from the next unit so that grammar progression can be judged in use. Do not author units 3–36 or treat passing tests as product acceptance.

## Failure audit and execution rules

The prior plan already required teaching before testing, real progression, language-first layouts and natural continuation. The implementation did not meet it. The first attempt compressed all required controls into one lesson. The second removed recall and called a keyboard check a learning activity. Neither was a basis for expansion.

These are implementation checks, not learner copy:

- Every question below has earlier preparation, a purpose and a bounded response. Every distractor is taught or glossed. Check those facts against the executable sequence.
- Vocabulary is added in small groups; earlier language returns after intervening tasks and in subsequent lessons. Show the actual return in the course, not merely a future unit number.
- New grammar is modelled, contrasted, built and retrieved. Reading/chat tasks ask for information or a meaningful response, not speaker-label trivia.
- No copy exercise, keyboard trainer, separate exercise-test route, “no free typing” promise, invented duration, or learner-facing assessment accounting.
- Reuse the existing course shell, brand and navigation. Course continuation advances to an authored next lesson. Partial work resumes. Completion has clear course/home destinations.
- Choices, banks, matching and gaps are reused/improved; live multi-turn replies and a focused sentence-edit task have distinct learner actions. A bubble alone is not a new exercise family.
- Correct after hint/reveal remains positive. It never earns independent-recall evidence. A partial known word is an error with a short correction. Unknown natural wording stays neutral.
- Inspect the actual exercise content and desktop/phone screenshots. Check wrong, alternative, help, reload, repair and continuation paths. Report language-review limitations honestly.

## Question-by-question contract (before implementation)

All typed answers ignore case, punctuation and NFC differences. `Ačiu`, `Aciu` and `prasom` receive a distinct spelling correction: the word is recognized, while accurate spelling remains unresolved. The [shared assessment contract](answer-assessment.md) defines the task-level policy, evidence and required wider integration. A short partial known word is wrong, not unassessable. Choice and bank order is shuffled once per run and saved, so position is not an answer cue. All tasks have an authored attention cue, a scoped reference and a separate reveal; help never leaks to the next task. Choosing a word bank on a retrieval task is recorded as requested support. Instruction and ordinary visible scaffolding are not remedial help.

### 1. Hello and thank you

New chunks: Labas, Ačiū, Prašom. No unsupported writing. Meaning, use and distinction precede later recall.

| ID | Exact learner task | Preparation, grading, purpose and return |
| --- | --- | --- |
| hello-model | Labas! — Hello! / Ačiū! — Thank you! | Model two meanings. |
| hello-choice | Hello! → choose Labas! / Ačiū! | Recognize modelled greeting. Wrong contrasts thanking. |
| thanks-meaning | Ačiū! → choose Thank you! / Hello! | Interpret thanks, reverse direction. |
| hello-meaning | Labas! → choose Thank you! / Hello! | Return after thanks, distinguish rather than one repeated target. |
| thanks-choice | Thank you! → choose Ačiū! / Labas! | Return with reversed direction. |
| reply-model | Ačiū! — Thank you! → Prašom! — You’re welcome! | Model a response to thanks; do not imply all senses of Prašom taught. |
| reply-meaning | Prašom! → choose You’re welcome! / Thank you! | Understand new response, contrast with incoming utterance. |
| thanks-reply | Ačiū! → choose Prašom! / Labas! | Take appropriate social turn; normal model is not a hint. |
| first-match | Match Labas / Ačiū / Prašom with Hello / Thank you / You’re welcome | Retrieve all three mappings in one board; mismatches identify the specific confusion. |
| first-reading | Exchange: Ačiū! / Prašom! → What does the second message do? Acknowledge thanks / Say hello | Reading tests meaning of the reply, not labels. |
| greeting-return | Labas! → reply Labas! / Prašom! | Discriminate greeting from thanks-response after intervening tasks. |
| thanks-return | You’re welcome! → choose Prašom! / Ačiū! | End with supported retrieval; returns in 2, 3 and 4. |

### 2. Give your name

New chunks: Mano vardas …; Koks tavo vardas? Build and interpret before producing; names are given proper names, not vocabulary to guess.

| ID | Exact learner task | Preparation, grading, purpose and return |
| --- | --- | --- |
| name-model | Mano vardas Rasa. — My name is Rasa. / Mano vardas Tomas. — My name is Tomas. | Highlight fixed frame vs replaceable name. Explain mano = my, vardas = name. |
| name-meaning | Mano vardas Rasa. → My name is Rasa / Your name is Rasa | Interpret mano (my), rather than merely spot a repeated proper name. |
| name-bank | My name is Tomas. → bank Tomas / vardas / Mano | Construct learned frame; no answer printed alongside. Accept Mano vardas Tomas / Tomas mano vardas. |
| name-gap | Mano ___ Lina. (My name is Lina.) → vardas / labas | Familiar naming frame; Lina supplied as proper name. |
| thanks-recall | Thank you! → write one word; Use words available | First text recall only after repeated recognition and intervening naming. Accept Ačiū / dėkui; known greeting wrong; schedule supported repair after other work if needed. |
| name-question-model | Koks tavo vardas? — What is your name? → Mano vardas Lina. | Teach asking one person informally, model the reply. |
| question-meaning | Koks tavo vardas? → What is your name? / My name is Rasa. | Distinguish question from introduction. |
| meet-greeting | Rasa: Labas! → choose Labas! / Prašom!; next incoming Koks tavo vardas? | Actual first turn; conversation continues into next question. |
| meet-name | Retain exchange, Rasa asks name; Reply as Tomas → bank Mano / Tomas / vardas | Actual second turn; Rasa then introduces herself. Recorded transcript survives reload. |
| name-reading | Labas! Mano vardas Lina. Koks tavo vardas? → What does Lina ask for? Your name / A thank you | Extract intent from Lithuanian using taught language. |
| reply-return | Ačiū! → choose Prašom! / Labas! | Space earlier reply before later productive return. |

### 3. I am, you are

New contrast: aš/tu and esu/esi, taught as two linked person/form pairs. No full conjugation table or role vocabulary prerequisites.

| ID | Exact learner task | Preparation, grading, purpose and return |
| --- | --- | --- |
| person-model | Aš esu Rasa. — I am Rasa. / Tu esi Tomas. — You are Tomas. | Highlight esu / esi. Explain aš → esu; tu → esi (one familiar person). |
| i-form | Aš ___ Tomas. → esu / esi | Choose form for explicitly supplied person. |
| you-meaning | Tu esi Rasa. → You are Rasa / I am Rasa | Interpret grammatical person. |
| you-form | Tu ___ Lina. → esu / esi | Apply contrast to new name; names do not change the verb. |
| i-bank | I am Tomas. → bank esi / Tomas / Aš / esu | Construct; distractor is the taught other-person form. |
| thanks-spaced | Thank you! → choose Ačiū! / Prašom! | Intervening earlier vocabulary before grammar retrieval. |
| fix-person | I am Lina. / Aš esi Lina. → select the wrong word, replace it with esu | Detect and repair form, rather than select entire sentence. Source fixes intended person. |
| i-form-recall | Aš ___ Lina. → write missing word; Use words available | Retrieve only esu after multiple examples. Wrong esi gets person-specific correction. |
| person-contrast | I am Rasa. → Aš esu Rasa / Tu esi Rasa | Interpret person in the reverse direction after retrieval. Both names are identical, so spotting a name cannot solve it. Replaces the weak same-person reading question found during audit. |
| you-form-recall | Tu ___ Tomas. → write missing word; Use words available | Retrieve esi after person-meaning work; wrong esu gets tu/esi correction. |
| reply-recall | Ačiū! → write a reply; Use words available | Reply introduced in 1 and returned in 2; no forced full sentence. Accept Prašom / nėra už ką; incomplete Praš is concise error. |

### 4. Meet someone

No new vocabulary. Select one of two authored name variants at run start; persist it. The demand combines a greeting, a name question and self-reference. A replay is practice, not an unseen check.

| ID | Exact learner task | Preparation, grading, purpose and return |
| --- | --- | --- |
| final-greeting | Lina (or Rasa): Labas! → choose Labas! / Ačiū! | Live exchange turn 1; next incoming asks name. |
| final-name | Retained exchange: Koks tavo vardas? / Reply as Tomas (or Mantas) → Aš esu Tomas / Tu esi Tomas | Respond about self, discriminate person. Then partner gives own name. |
| final-reading | Exchange: Mano vardas Lina. / Mano vardas Tomas. → choose matching English description | Combine the two facts; alternatives swap self/other meaning without answer in speaker label. |
| final-form | Tu ___ Rasa. → write missing form | Transfer taught person rule to another example. |
| final-thanks | Thank you! → write one word | Retrieve after other language. |
| final-name-bank | My name is Mantas. → build from Mano / vardas / Mantas / tavo | `tavo` was taught in lesson 2. Its meaning is available in the requested hint; no floating distractor gloss. No sentence typing. |
| final-reply | Ačiū! → choose Prašom! / Labas! | End with familiar social use. |

## Error repair and evidence

At most one supported repair per target and three per lesson. Insert after two intervening questions where possible. Repair shows a targeted contrast and asks a bounded choice on another example. A repair is practice; it cannot establish unassisted recall. No endless retry loop or completion penalty for requested help. Existing scheduled returns in later lessons still occur after successful/assisted first attempts.

Record target, ability, actual response mode, correctness, built-in support, requested help and timestamp separately. Form-gap recall is evidence for that form only, not every word in the sentence. Recognition and successful bank construction never become independent production. Keep v1/v2 preview and historical app records untouched; this contract has its own versioned store. Do not claim delayed recall from same-session returns; actual next-day scheduling remains Stage B.

## Implemented review, 24 September 2026

The executable route contains 41 authored steps: five teaching models and 36 tasks across four lessons. Matching records each pair separately as well. A wrong answer can add a bounded repair; the phone walkthrough deliberately produced one and completed 42 steps. Counts describe the route, not a learning-time estimate or evidence of efficacy.

The content audit removed two answer shortcuts before review: a name-recognition choice that could be solved by matching a proper name now contrasts “my” versus “your”; a same-person reading question solvable from repeated names became a direct aš/tu contrast with identical names in both options. Reading remains where the task actually requires understanding an utterance or request. Hints now guide attention; full answers belong to reference/reveal. Choice and bank orders are saved with each run.

Concrete progression:

- Lesson 1 models and distinguishes three social chunks, then asks for meaning, appropriate replies, a matching board and comprehension of an exchange.
- Lesson 2 teaches a naming frame before construction, returns to `Ačiū` after naming work, teaches the name question, and keeps a two-turn greeting/name conversation alive across submissions.
- Lesson 3 introduces the two person/form pairs, highlights their contrast, asks for selection and construction, interrupts with earlier vocabulary, asks the learner to find and fix the wrong verb, then retrieves one form at a time. `Prašom` returns here after two lessons of preparation.
- Lesson 4 selects and preserves an authored conversation variant, combines self-reference with the name question, and returns to form, naming and thanks. It contains no new vocabulary prerequisites.

The first production question is one previously practised word. “Use words instead” provides help if retrieval is too hard. Later production is also bounded to a word or missing form. There is no unprepared full-sentence writing and no copy task. This is a limited representative course slice; the outline is not expanded into six or 36 units.
